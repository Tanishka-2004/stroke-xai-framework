Kaggle stroke prediction dataset — 5-stage CatBoost framework

Production-grade machine learning architecture evaluated on the public Kaggle stroke dataset (N=5,110, 4.87% prevalence, held-out test N=1,022).

Stage 1
Clinical preprocessing
Median BMI imputation (28.1), outlier removal, leakage-free 80/20 split.
Stage 2
Cost-sensitive CatBoost
19.54:1 class weighting, symmetric trees, native categorical handling.
Stage 3
Probability calibration
5-fold OOF Platt sigmoid scaling. Brier 0.170 → 0.041.
Stage 4
SHAP interpretability
Global rankings, patient waterfall plots, age x glucose interaction.
Stage 5
Reliable evaluation
Demographic parity audit, decision-curve analysis.

Stage 5: subgroup demographic audit

Limitations

Model performance varies substantially by age group. AUC 0.628 for Age <55 and 0.563 for Age >70 are weak — these subgroups should not be relied upon for clinical triage. Likely caused by low event counts and covariate shift in the Kaggle dataset.
